# Time Work

تطبيق Android ثنائي اللغة (العربية / English) لتسجيل ساعات العمل، الساعات الإضافية، والأجر.

## النسخة الأولى
- زر دائري لبدء يوم العمل.
- عداد مباشر أثناء العمل.
- عند الضغط أثناء التشغيل يظهر تأكيد: هل انتهى يوم عملك؟
- حفظ وقت البدء والنهاية والمدة محليًا.
- العربية RTL والإنجليزية LTR.
- إعداد أجر الساعة وساعات الدوام ومعامل الإضافي.
- تقارير وإحصائيات أولية.
- صفحة About وبيانات المطور.

## Planned feature: Monthly History / سجل الشهور

- حساب الشهر حسب التقويم الميلادي من أول يوم إلى آخر يوم في الشهر.
- بدء إحصائية شهر جديد تلقائيًا عند دخول شهر جديد دون حذف الأشهر السابقة.
- شاشة لسجل الشهور السابقة.
- عرض إجمالي ساعات العمل لكل شهر.
- عرض عدد أيام العمل لكل شهر.
- عرض الساعات الإضافية لكل شهر.
- عرض إجمالي الأجر لكل شهر.
- فتح أي شهر لعرض تفاصيل كل يوم داخله.
- تفاصيل اليوم تشمل وقت البدء، وقت الانتهاء، إجمالي الساعات، الساعات الإضافية، والأجر.
- إمكانية الرجوع إلى أي شهر سابق لاحقًا.
- تنظيم السجل بالشكل: السنة ← الشهر ← الأيام ← تفاصيل يوم العمل.
